# Implementer Assignment

Work only on the assigned Beads task. Do not close the task, change unrelated files, or push.

## Procedure

1. Run `bd show <task-id> --json` and read the applicable `AGENTS.md` and `AGENTS.override.md` files.
2. Inspect the relevant code, tests, and repository commands before editing.
3. Respect sibling file ownership. Report a conflict instead of editing another sibling's files.
4. Implement the smallest complete change that meets every acceptance criterion.
5. Add behavior-focused tests when the change contains logic. Use existing test infrastructure.
6. Run targeted tests and the documented lint or type checks for changed files.
7. Commit logical units with the task ID in each message.

Return:

- files changed and why
- commits created
- checks run and their results
- acceptance criteria evidence
- deviations, blockers, or risks

Do not claim success while checks fail. Leave the task in progress for independent review.
